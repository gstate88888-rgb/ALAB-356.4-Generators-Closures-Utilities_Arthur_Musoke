# ALAB 356.4 \- Generators, Closures, and Utility Methods

## Description

This lab demonstrates several advanced Python concepts including generators, closures, file handling, and utility modules.

### Programs Included

#### fibonacci\_generator.py

Uses a generator function to produce Fibonacci numbers up to a user\-specified count.

#### multiplier\_closure.py

Demonstrates closures by creating customized multiplier functions that retain their multiplication factor.

#### diary.py

Uses file I/O, the os module, and datetime module to create and maintain a diary file with timestamped entries.

#### calendar\_utility.py

Uses the calendar and datetime modules to display monthly calendars and determine whether today's date falls within the selected month.

## Concepts Demonstrated

- Generators and yield
- Closures and nested functions
- File input/output
- Exception handling
- os module
- datetime module
- calendar module
